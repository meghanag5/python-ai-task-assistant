# Python AI Task Assistant

Python Practice with OOP, APIs, async programming, and Git workflow.
This project is designed as a command lone productivity assistant where users can manage tasks, track completion status, and build toward more advanced AI-Agent style workflows
## Current Features
- Add new tasks
- View all tasks
- Mark tasks as complete
- Save tasks automatically using JSON
- Load saved tasks when the program starts
- Object-Oriented Programming using a `Task` class
- Task serialization and deserialization (`to_dict()` + JSON loading)

## Planned Features
- Save tasks to JSON
- Fetch motivational quotes from an API
- Add async API calls
- Expand into an AI-agent-style workfloww
